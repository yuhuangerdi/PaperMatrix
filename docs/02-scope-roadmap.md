# 功能分级与路线图

## L0：平台基础

- 本地自托管 Web 运行模式；
- 工作区、项目、配置和文件安全；
- 统一错误、日志、诊断和版本迁移；
- Vue/Python 工程质量体系。

## L1：论文整理核心（MVP）

### 项目与论文

- 多项目；
- PDF 路径引用导入；
- 元数据和阅读状态；
- 文件缺失检测与重新关联。

### 单篇阅读

- 老师七项阅读重点；
- 当前模板完整 Markdown 与稳定条目身份；
- 论文研究问题、方法、实验等条目的章节定位和手动关系；
- 独立个人补充笔记；
- 扩展批判性评价和写作用途；
- 页码、图表和证据定位。

### 跨论文分析

- 可复现的分析集合与分析准备度；
- 多个领域问题归纳板；
- 每篇论文“方法/解决程度”双列问题矩阵；
- 文献矩阵和上下文编辑；
- 带定义与证据的方法分类；
- 挑战—方案矩阵及热力视图；
- 实验矩阵、比较组和可比性判定；
- 关系网络图与等价邻接表；
- 共识、冲突和假设主张；
- 研究空白证据链；
- 绑定分析集合的综合分析工作台。

阶段 4 是 L1 的核心，按 `docs/17-analysis-core.md` 拆为 4A–4E。4A 先完成完整 Markdown 条目化、个人补充笔记、条目关系和稳定跳转；4B 优先完成领域问题归纳，再进入方法/挑战/实验比较。关系图只是其中一个视图，不能替代问题贡献、实验口径、主张证据和研究空白推导。

### 输出

- 一页汇报摘要；
- Markdown 综合分析；
- CSV/XLSX 导出。

## L2：研究效率增强

- 内置 PDF 预览、页码跳转；
- BibTeX、RIS、DOI 元数据补全；
- 项目内全文索引；
- 自定义字段和模板；
- XLSX 受控导入与冲突预览；
- 标签规则、批量编辑和保存视图；
- 图关系过滤和 GraphML 导出。

## L3：可插拔语言与 AI 能力

### 翻译模块

- 逐段或全文翻译任务；
- 原文—译文对齐；
- 术语表；
- 任务断点和成本提示；
- 不自动覆盖原文。

### 自动分析模块

- 从论文提取结构化字段；
- 生成候选摘要而非直接写入；
- 每个结论附页码或原文证据；
- 置信度与人工确认；
- 支持本地模型或用户自选服务商。

### 跨论文智能分析

- 项目 RAG；
- 经典文献和方法路线候选；
- 共识、冲突和研究空白建议；
- 相关工作草稿；
- 严格区分“文献事实”和“模型推断”。

## L4：团队与生态

- 远程部署、认证和权限；
- 项目共享和审阅；
- 版本历史和冲突合并；
- 插件系统；
- 引文管理器、云盘和代码仓库连接。

## 分级原则

- L1 不依赖 AI，必须独立完整可用；
- L2 提升整理效率，但不得破坏文件透明性；
- L3 所有网络上传必须显式触发并展示范围；
- L4 必须重新评估身份、权限、加密和合规，不得沿用单用户假设。

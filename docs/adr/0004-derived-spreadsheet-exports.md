# ADR-0004：Excel/CSV 作为派生矩阵而非唯一权威数据

- 状态：Accepted
- 日期：2026-07-26

## 背景

用户希望使用 Excel 风格矩阵，但单个 XLSX 难以安全支持局部写入、并发、schema 迁移和长文本。

## 决策

YAML/Markdown 为权威来源；应用按需生成 XLSX/CSV。MVP 的外部手工修改不会自动反向同步。

所有示例和导出模板统一保存在仓库根目录 `templates/`。论文字段、笔记结构、问题、关系、矩阵或导出格式发生变化时，必须在同一任务中核对并按需更新模板。

## 结果

保证核心数据稳定、易 diff。用户仍能获得 Excel 进行查看和分享。未来若实现反向导入，必须先提供差异预览、字段校验和冲突处理。

# ADR-0002：业务数据使用普通文件而非数据库

- 状态：Accepted
- 日期：2026-07-26

## 背景

用户明确要求不使用数据库，希望表格和文档都以文件形式在项目目录管理。

## 决策

- 每篇论文元数据：独立 YAML；
- 每篇论文长笔记：Markdown；
- 项目关系和研究空白：YAML；
- 矩阵和汇报：CSV/XLSX/Markdown 派生文件；
- 使用 schema_version、文件锁、revision 和原子替换保证可靠性。

## 结果

优点：透明、可移植、可手工编辑和备份。代价：复杂查询和高并发能力弱，需要严格处理文件冲突和 schema 迁移。MVP 的单用户规模可接受。

# ADR-0001：采用本地优先 Web 架构

- 状态：Accepted
- 日期：2026-07-26

## 背景

用户要求 Vue 3 前端和 Python 后端，当前不打包桌面端，同时需要访问用户自己保存的论文文件。

## 决策

MVP 采用运行在用户本机的自托管 Web 应用：浏览器访问本机 FastAPI，后端负责访问本机文件系统，默认监听 127.0.0.1。

## 结果

优点：保留 Web 技术栈、开发简单、后端可安全处理路径。限制：浏览器无法把访问者电脑真实路径直接交给远程服务器，因此远程部署不能读取访问者本机文件。远程模式未来需重新设计上传、同步或客户端代理。

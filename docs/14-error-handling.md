# 错误码与恢复策略

## 错误响应字段

- `code`：稳定机器码；
- `message`：用户可理解描述；
- `details`：字段或资源信息；
- `action`：建议动作；
- `request_id`：诊断标识。

## 初始错误码

| 错误码 | HTTP | 含义 | 用户动作 |
|---|---:|---|---|
| PM-CONFIG-001 | 400 | 工作区未初始化 | 完成首次设置 |
| PM-CONFIG-002 | 422 | 工作区配置损坏 | 查看诊断并修复 YAML |
| PM-PATH-001 | 400 | 路径格式无效 | 检查输入 |
| PM-PATH-002 | 403 | 路径不在允许根 | 在设置中添加根目录 |
| PM-PATH-003 | 403 | 符号链接越界 | 选择真实允许路径 |
| PM-PATH-004 | 404 | 路径不存在 | 修正路径或重新关联 |
| PM-PATH-005 | 403 | 工作区或论文根目录权限不足 | 选择具有所需权限的目录 |
| PM-FILE-001 | 422 | YAML/Markdown 解析失败 | 查看文件位置和错误行 |
| PM-FILE-002 | 422 | Schema 校验失败 | 修复字段或恢复兼容版本 |
| PM-FILE-003 | 423 | 文件锁超时 | 稍后重试或关闭其他编辑页 |
| PM-FILE-004 | 409 | 文件被外部修改 | 重新加载并合并 |
| PM-PROJECT-001 | 404 | 项目不存在 | 返回项目列表 |
| PM-PROJECT-002 | 409 | 项目名称/slug 冲突 | 修改名称 |
| PM-PROJECT-003 | 409 | 项目包含业务文件，不能删除 | 先清空记录或归档项目 |
| PM-PAPER-001 | 404 | 论文记录不存在 | 刷新列表 |
| PM-PAPER-002 | 409 | 重复导入 | 打开已有记录 |
| PM-PAPER-003 | 422 | PDF 元数据读取失败 | 仅登记路径并手工补充 |
| PM-PAPER-004 | 409 | 源 PDF 已变化 | 确认更新指纹或重新关联 |
| PM-PAPER-005 | 413 | 单文件上传超过读取上限 | 改用允许目录路径登记 |
| PM-QUESTION-001 | 404 | 问题记录不存在 | 刷新问题列表 |
| PM-ANALYSIS-001 | 404 | 单篇分析条目不存在 | 刷新论文分析条目 |
| PM-ANALYSIS-002 | 409 | 候选预览对应的笔记或论文版本已变化 | 重新解析并再次审阅 |
| PM-ANALYSIS-003 | 422 | 候选 ID 不属于当前解析结果 | 重新解析后再确认 |
| PM-CONFLICT-001 | 409 | revision 冲突 | 比较版本后重试 |
| PM-EXPORT-001 | 422 | 导出格式不支持 | 选择支持格式 |
| PM-EXPORT-002 | 500 | 导出失败 | 查看诊断，旧文件未被覆盖 |
| PM-NETWORK-001 | 客户端 | 无法连接本机后端或请求超时 | 启动后端并重试 |
| PM-NETWORK-002 | 客户端 | 服务响应格式无法识别 | 稍后重试并查看诊断 |
| PM-INTERNAL-001 | 500 | 未知内部错误 | 复制 request ID |

## 恢复原则

- 解析失败：只读，不覆盖；
- 保存失败：保留前端草稿；
- 导入部分失败：成功项保留，逐项报告；
- 导出失败：旧导出保留；
- 源文件缺失：保留记录和笔记；
- revision 冲突：不采用最后写入覆盖。

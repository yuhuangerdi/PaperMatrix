# 验收标准

## A. 阶段 0

### AC-0001 工程启动

- 后端可通过文档命令启动；
- 前端可通过文档命令启动；
- 前端显示 `/api/v1/health` 返回状态；
- 根级验证命令返回成功。

### AC-0002 无数据库

- 依赖中没有数据库驱动、ORM 或迁移工具；
- 运行时不创建 `.db`、SQLite、IndexedDB 业务存储；
- 项目数据只存在规定文件中。

### AC-0003 原子写入

- 写入中断测试保留旧文件；
- 并发 revision 测试返回冲突；
- 临时文件被清理。

### AC-0004 路径安全

- 允许根内 PDF 可读取；
- `../`、符号链接越界和未配置根被拒绝；
- API 不能读取任意系统文件。

## B. 工作区和项目

### AC-0101 初始化工作区

- 新目录能创建标准结构；
- 无写权限目录给出可操作错误；
- 已存在有效工作区能读取；
- 损坏 workspace.yaml 不会被覆盖。

### AC-0102 项目 CRUD

- 创建后生成 project.yaml；
- 修改 revision 增加；
- 项目列表统计正确；
- 删除空项目只删除项目内部文件。

## C. 论文导入

### AC-0201 不复制 PDF

- 导入前后 PDF 路径、大小、mtime、hash 不变；
- 工作区中不出现 PDF 副本；
- paper.yaml 保存引用路径。

### AC-0202 重复与异常

- 同项目重复路径不会产生第二条记录；
- 损坏 PDF 可选择只登记；
- 单个 PDF 上传只创建未关联记录，工作区不保存 PDF 副本；
- 没有 PDF 时可仅凭标题创建记录并在之后重新关联；
- 论文基础信息和项目内分组写回独立 YAML，并支持列表筛选；
- 单个失败不阻断其他文件导入；
- 单个不符合当前 Paper Schema 的记录不阻断列表；界面单独列出并允许确认后仅删除 PaperMatrix 文件；
- 结果清单区分成功、跳过和失败。

### AC-0203 删除记录

- UI 明示原 PDF 不删除；
- 删除后 paper YAML、note 和关系引用被清理；
- 源 PDF hash 不变。

## D. 笔记和矩阵

### AC-0301 笔记模板

包含老师七项、批判性评价、关系、写作用途和关键页码。第 0–12 节始终保存为一份完整 Markdown；确认条目具有稳定 ID、模板章节、顺序和来源锚点，论文研究问题是正式结构化条目。

### AC-0302 保存可靠性

- 自动保存可见；
- 冲突不覆盖；
- 网络/后端错误后草稿仍在；
- Markdown 可直接用文本编辑器读取。
- 完整文档模式和条目模式往返不丢内容、不重排无关段落；
- 个人补充笔记独立保存、独立冲突，导出合并不覆盖源文件。

### AC-0401 文献矩阵

- 可搜索、筛选、排序和列显隐；
- 1,000 行数据基本可用；
- 核心编辑写回 YAML；
- 导出内容与当前数据一致。

### AC-0402 跨论文分析

- 可建立明确论文 ID 的分析集合，缺失记录不会被静默移除；
- 可维护多个问题归纳板，阅读问题、论文研究问题和领域问题不混用；
- 领域问题可映射多篇论文的研究问题条目；
- 问题归纳表中每篇论文固定分为“方法”和“解决程度”两个独立单元格；
- 解决程度七态包含理由、证据、反证和条件；“未解决”与“未涉及”可区分，存在方法不会自动判定问题已解决；
- 条目关系支持同篇/跨篇、反向引用、删除影响检查和悬空引用诊断；
- 方法分类包含定义与证据，挑战矩阵五态可编辑；
- 实验比较显示可比、部分可比、不可比或未知及理由；
- 不可比实验不排名，不把未知当作零；
- 可维护关系、共识、冲突、假设和研究空白；
- 主张同时支持支持证据和反证；
- 研究空白可关联多篇证据，并包含可检验问题和验证计划。

### AC-0403 可视化与可访问性

- 问题归纳双列矩阵与按问题展开列表同源；
- 方法和解决程度不只依赖颜色，移动端可以分别检查和编辑；
- 关系图、邻接表和关系编辑使用同一权威数据；
- 关系图支持范围、类型、时间和分组筛选，筛选不删除数据；
- 挑战热力矩阵与文本表格同源；
- 图形不只依赖颜色，键盘用户可通过表格完成同等操作；
- 移动端可完成分析集合切换、关系查看和证据检查；
- 1,000 篇项目只加载当前分析子图。

### AC-0404 证据与综合分析

- 任一问题归纳方法、解决程度和理由可跳回完整笔记的稳定条目；
- 任一关系、主张和研究空白可跳回论文条目或明确标记待补证据；
- 只有一篇支持时不会显示为领域共识；
- 综合分析绑定分析集合且显示纳入范围；
- 缺失内容不被自动推断；
- 重新生成不会覆盖用户已编辑正文。
- 综合分析包含当前范围的领域问题、各论文方法、解决程度和未决问题，不创造缺失判断。

## E. 导出

### AC-0501 CSV/XLSX

- 中文正常；
- 列顺序稳定；
- 公式注入被防护；
- 默认不覆盖同名导出；
- 导出失败不破坏已有文件。

### AC-0502 Markdown

- 一页汇报摘要包含七项主结构；
- 缺失内容明确标记待补充；
- 综合分析可直接打开编辑。

## F. 发布前总验收

- 所有自动化检查通过；
- 演示工作区完整跑通；
- Windows、macOS、Linux 至少完成路径测试；
- 无真实论文、密钥和个人绝对路径进入仓库；
- README 的安装运行步骤在干净环境验证。

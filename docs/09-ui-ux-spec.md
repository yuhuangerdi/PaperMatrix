# UI/UX 规范

## 1. 信息架构

左侧主导航：项目、当前项目模块、设置、诊断。项目内二级导航：总览、论文矩阵、分析工作台、导出。分析工作台内使用标签切换问题归纳、方法与挑战、实验、关系、主张与研究空白、综合分析，避免侧栏因阶段 4 扩展而持续变长。

顶部显示当前工作区和项目面包屑。涉及文件路径时明确标注“后端所在机器的路径”。

## 2. 视觉方向

- 学术工具风格：清晰、克制、信息密度适中；
- 主色不承担唯一语义；
- 表格、表单和长文本优先；
- 默认浅色，预留深色；
- 中文界面为默认，代码字段保持英文。

## 3. 核心交互

### 导入流程

1. 选择已配置论文根目录或输入子目录；
2. 选择是否递归；
3. 扫描后显示文件名、大小、修改日期、是否重复；
4. 用户勾选；
5. 导入确认明确写出“不复制、不移动原 PDF”；
6. 展示成功、跳过和失败清单。

### 删除记录

确认文案必须为：

> 此操作将删除 PaperMatrix 中该项目的论文记录、笔记及关系引用。原始 PDF 文件不会被删除或修改。

不要使用含糊的“永久删除论文”。

### 缺失 PDF

使用明显但非破坏性状态：源文件不可用。提供“重新关联”“查看原路径”“暂时忽略”。不得自动创建空 PDF 或删除记录。

### 笔记保存

- 显示“已保存/保存中/未保存/保存失败”；
- 自动保存间隔建议 1–2 秒防抖；
- 关闭页面时若未成功保存，阻止离开或允许复制草稿；
- 冲突时不能直接覆盖服务器版本。
- 结构化笔记必须保留当前模板的完整文档模式，并提供条目模式；两者共享保存状态和同一正文；
- 个人补充笔记具有独立保存状态，不能因结构化笔记保存成功而误显示为已保存；
- 从项目级视图跳入笔记时展开章节、定位和高亮稳定 item ID，不能依赖行号。

## 4. 文献矩阵默认列

固定：论文简称、年份、会议/期刊、研究主题、解决问题、核心思路、阅读状态、重要性、写作用途。

可选：挑战、创新点、实验环境、基线、指标、开源、局限、关键页码、关系数量等。

## 5. 空状态

每个空状态同时说明“为什么为空”和“下一步动作”。例如项目无论文时显示导入入口和“不复制 PDF”的说明。

## 6. 错误提示

- 标题：用户能理解的问题；
- 正文：发生了什么；
- 动作：如何修复；
- 详情：可展开错误码和 request ID；
- 不直接展示 Python traceback。

## 7. 无障碍

- 所有输入有 label；
- 对话框焦点锁定并可 Esc 关闭；
- 表格操作有键盘替代；
- 状态图标包含文字；
- 对比度达到 WCAG AA 目标；
- 页面标题随路由更新。

## 8. 跨论文分析可视化

### 分析范围

分析集合选择器固定在工作区顶部，并同时显示论文数量和缺失引用。范围变化需要刷新全部分析标签；不得让关系图和矩阵悄悄使用不同集合。

### 关系图

- 图占据主内容区域，不放在卡片或预览框中；
- 工具栏使用搜索、筛选、适应视图、布局和保存视图图标按钮，并提供 tooltip；
- 右侧检查器显示节点或边的事实、关系方向、证据和编辑动作；
- 节点类型使用形状/图标与颜色共同表达，边类型使用线型、箭头和文字图例；
- 搜索聚焦、筛选隐藏，二者都不删除数据；
- 默认只渲染当前分析集合或筛选子图；
- 移动端默认进入邻接表，用户可主动切换图。

### 矩阵与热力视图

- 问题归纳矩阵以领域问题为行，每篇论文使用“方法/解决程度”两个可辨识子列；
- 方法和解决程度分别编辑，解决程度同时显示文字与理由，不得只用颜色或图标；
- 宽矩阵支持论文列组折叠、固定问题列、分页和等价按问题列表；
- 挑战矩阵的五种状态同时使用文字/符号和颜色；
- 点击单元格显示来源条目与证据，不在悬浮提示中塞入长文本；
- 实验比较把口径和结果分区展示，可比性警告位于数字之前；
- 网络图、热力图和时间线都提供可下载或可复制的同源表格。

### 主张和研究空白

- 支持证据与反证并列，不能把反证藏在折叠区；
- 单篇发现、共识、争议和假设使用明确文字；
- 研究空白按“局限证据 → 重复模式 → 未解决原因 → 研究问题 → 验证计划”展示；
- 信心和准备度不只依赖颜色，也不包装成论文质量分数。
